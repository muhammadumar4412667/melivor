MELIVOR WEBSITE — 18 PRODUCT VERSION

Files:
- index.html: complete Melivor homepage
- assets/melivor-hero-background.png: hero background artwork
- assets/products/: 18 product photos

How to use:
1. Extract this ZIP.
2. Copy index.html and the entire assets folder into your VS Code project folder.
3. Keep index.html and assets side by side.
4. Open index.html with VS Code and run Live Server.

The two new products added:
- Burgundy Floral Lace Bra Set
- Ruby Red Lace Bra Set

The displayed prices are demo prices. Update them to your actual store prices before launch.
